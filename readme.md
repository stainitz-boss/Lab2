# Домашнее задание к работе 2: Расчет выручки авиакомпании

## Условие задачи

> Реактивный аэробус летит с пассажирами на борту из Лондона в Нью-Йорк.  
> Три четверти пассажиров имеют билеты второго класса стоимостью **x** фунтов каждый.  
> Остальные пассажиры имеют билеты первого класса, которые стоят **вдвое дороже** билетов второго класса.  
> Напишите программу, которая выведет сумму денег, получаемую авиакомпанией от продажи билетов на этот рейс.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Объявить константы:**
   - `ps = 100` — общее количество пассажиров на борту.
   - `x = 500.0` — стоимость билета второго класса (фунтов).
3. **Вычислить стоимость билета первого класса:**
   - `a = x * 2`
4. **Вычислить количество пассажиров каждого класса:**
   - `x_ps = ps * (3.0 / 4.0)` — три четверти пассажиров (2-й класс).
   - `a_ps = ps - x_ps` — остальные пассажиры (1-й класс).
5. **Вычислить общую сумму выручки:**
   - `total_sum = (a_ps * a) + (x_ps * x)`
6. **Вывести результаты расчетов с подстановкой всех значений в текст.**
7. **Конец**

## 2. Реализация программы

```
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    // константы
    const int ps = 100;      // кол-во пассажиров
    const float x = 500.0;   // цена билета 2-го класса

    // вычисления
    float a = x * 2;                  // цена билета 1-го класса
    float x_ps = ps * (3.0 / 4.0);    // кол-во пассажиров из 2-го класса
    float a_ps = ps - x_ps;           // кол-во пассажиров из 1-го класса
    float total_sum = (a_ps * a) + (x_ps * x); // общая сумма денег

    printf("РАСЧЕТ ВЫРУЧКИ АВИАКОМПАНИИ ЗА РЕЙС\n");
    printf("===================================\n\n");

    printf("УСЛОВИЯ:\n");
    printf("- Общее количество пассажиров: %d чел.\n", ps);
    printf("- Стоимость билета 2-го класса: %.2f фунтов.\n", x);
    printf("- Доля пассажиров 2-го класса: 3/4 от общего числа.\n\n");

    printf("РАСЧЕТ:\n");
    printf("- Стоимость билета 1-го класса: %.2f * 2 = %.2f фунтов.\n", x, a);
    printf("- Пассажиров 2-го класса: %d * (3/4) = %.0f чел.\n", ps, x_ps);
    printf("- Пассажиров 1-го класса: %d - %.0f = %.0f чел.\n", ps, x_ps, a_ps);
    printf("=============================================\n");

    printf("ОБЩАЯ СУММА ВЫРУЧКИ ЗА РЕЙС: %.2f фунтов.\n", total_sum);

    return 0;
}
```
